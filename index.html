IDM Metrics Collector

Die professionelle Monitoring-Plattform mit integrierter KI-Anomalieerkennung, Home Assistant Integration und vollautomatischer Steuerung für IDM Navigator 2.0 Wärmepumpen.

GitHub Repository Dokumentation (Wiki)

Features im Überblick

🤖
KI-Anomalieerkennung

Machine Learning erkennt Abweichungen im Verhalten der Wärmepumpe frühzeitig.

📊
Echtzeit-Überwachung

Live-Daten aller Sensoren auf einen Blick im intuitiven Dashboard.

📈
Langzeitanalyse

Speicherung aller Daten in VictoriaMetrics und Visualisierung in Grafana.

🏠
Home Assistant

Nahtlose Integration in Ihr bestehendes Smart Home über MQTT.

⚡
Vollautomatisierung

Intelligente Zeitpläne und automatische Anpassung der Vorlauftemperatur.

🔒
100% Lokal & Sicher

Keine Cloud-Zwang, Ihre Daten bleiben bei Ihnen im lokalen Netzwerk.

Installation

Die Installation erfolgt am einfachsten über Docker Compose. Alle benötigten Dienste (Metrics Collector, VictoriaMetrics, Grafana, ML-Service) werden automatisch eingerichtet.

Kopieren mkdir idm-metrics cd idm-metrics curl -O https://raw.githubusercontent.com/Xerolux/idm-metrics-collector/main/docker-compose.yml curl -O https://raw.githubusercontent.com/Xerolux/idm-metrics-collector/main/config.yaml.example mv config.yaml.example config.yaml # config.yaml anpassen (IP der Wärmepumpe eintragen) docker-compose up -d

Ausführliche Installationsanleitungen finden Sie in unserem Wiki.

## 2026-02-19 - Hybrid Input Controls
**Learning:** Combining `InputNumber` with `Slider` (bound to the same v-model) provides excellent UX for numeric ranges—offering both rapid adjustment (slider) and precision (input).
**Action:** Use this "Hybrid Input" pattern for any future 0-10 or percentage-based configuration settings.
